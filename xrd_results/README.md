# WAAM IN718 盐雾腐蚀后 GI-XRD 处理结果

本目录包含三组入射角（0.2°、0.5°、1°）的处理数据、图表、峰拟合结果、分析报告和可复现脚本。

- `XRD_processed.xlsx`：完整处理数据和拟合表
- `分析报告.md`：结论、局限性与后续测试建议
- `comparison.*`：三组曲线对比
- `raw_and_background.*`：原始曲线与背景
- `peak_fit_diagnostics.*`：候选峰拟合诊断
- `*_processed.csv`：各扫描逐点处理数据
- `process_xrd.py`：处理脚本

压缩包位于仓库根目录的 `XRD_results.zip`。
